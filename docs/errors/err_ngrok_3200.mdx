# 🗒️ Note Taking App (Android + Flask)

This is a simple note-taking application built with:
- Kotlin Android App using Retrofit
- Flask REST API backend with SQLite
- Connected via ngrok for testing

## 🧪 API Endpoints

| Method | Endpoint               | Description        |
|--------|------------------------|--------------------|
| GET    | /get_notes             | Get all notes      |
| POST   | /add_note              | Add a new note     |
| PUT    | /update_note/<id>      | Update a note      |
| DELETE | /delete_note/<id>      | Delete a note      |
